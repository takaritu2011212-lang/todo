# NEXUS Web - Character Edition

ダークな近未来UIのタスク・予定管理アプリです。GitHub Pagesでそのまま公開できる静的Webアプリです。

## 主な機能
- タスクの追加・編集・削除・完了、期限・優先度の管理
- 予定の追加・編集・削除
- キャラクターの作成・編集・削除
- キャラクターごとの名前、性格、口調、最初のひとこと、立ち絵画像の設定
- デフォルトキャラクター「リオン」と専用立ち絵（`rion.svg`）
- キャラクターを選んで会話（端末内のルールベース辞書・優先フレーズ・ランダム応答）
- Excel（.xlsx / .xls）辞書の読み込み、JSON辞書の読み込み・書き出し
- キャラクターごとの辞書・定型文・優先フレーズ・イベント・フラグを管理
- 好感度、関係段階、感情、イベントフラグの表示
- 短期・長期記憶の確認、長期記憶への保存、個別削除、定期的な声かけ
- localStorageによる端末内保存、JSONバックアップ
- Service Workerによる基本キャッシュ

## GitHub Pagesで公開
1. このリポジトリの **Settings → Pages** を開きます。
2. **Deploy from a branch** を選択します。
3. Branchを `main`、フォルダを `/(root)` にして保存します。
4. 表示されたPages URLを開きます。

## 使い方
- **キャラクター**から「新規作成」を押し、名前・性格・口調などを入力します。
- 立ち絵はPNG / JPG / WebP / SVGに対応。ブラウザ内にデータとして保存します。容量節約のため画像は1.2MB以下を推奨します。
- **会話**ページで話す相手を切り替えられます。
- 画面右下のマスコットを開き、「Excel / JSON取込」から辞書を読み込めます。Excelの「03_キャラクター」で有効なキャラクターを読み込み対象にします。
- 「JSON書出し」で選択中キャラクターの辞書を保存できます。Excelを編集して別キャラを作る場合は、キャラクターIDと名前を変更し、アップロードしてください。
- **バックアップ**ボタンでJSONを書き出せます。バックアップ読み込みはボタンをダブルクリックしてファイルを選択します。

## 注意
- 会話は辞書・定型文・条件分岐によるローカルルールベースです。外部AI APIには接続していません。
- Excel読込時はSheetJSライブラリをCDNから読み込みます。Excel読込にはインターネット接続が必要です。JSON辞書の読み込みは外部ライブラリを必要としません。
- 検索はGoogle検索ページを開くだけです。検索結果の取得、解析、要約はしません。
- データは利用中のブラウザ・端末内に保存され、端末間同期はありません。ブラウザデータを消す前にバックアップしてください。
- 通知はブラウザや端末の動作状態に左右されます。タブを閉じた状態での通知は保証されません。
- キャラクター画像を大量に登録すると、ブラウザの保存容量に達する場合があります。
