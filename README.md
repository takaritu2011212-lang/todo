# NEXUS Web Prototype

ダークな近未来UIを持つ、オフライン対応を目指したタスク・予定管理PWAです。

## 機能
- タスクの追加、編集、削除、完了、期限と優先度
- 予定の追加、編集、削除、リマインダー
- ローカルルールベースのキャラクター「リオン」との会話
- `localStorage` による端末内保存
- JSONバックアップの書き出し・読み込み
- Service Workerによるアプリシェルのキャッシュ
- ブラウザ通知（通知許可とブラウザの稼働状態に依存）

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成（例：`nexus-web`）。
2. このフォルダ内の `index.html`、`style.css`、`app.js`、`manifest.json`、`sw.js`、`README.md` をリポジトリ直下へアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選択し、`main` ブランチの `/(root)` を指定して保存。
5. 数分後、表示されたGitHub Pages URLを開く。初回はオンラインで読み込み、Service Workerの登録後にオフラインキャッシュが利用できます。

## 注意
- キャラクター会話は外部AIを使わないルールベースの簡易実装です。
- データはブラウザごと・端末ごとに保存され、端末間で同期されません。ブラウザデータの消去で失われることがあるため、バックアップ機能を利用してください。
- ブラウザ通知はHTTPS（GitHub Pagesは対応）とユーザーの許可が必要です。モバイルブラウザでは、タブを閉じている間の予約通知やバックグラウンド動作が保証されません。
- これは試作版です。実際の公開前に各ブラウザで動作確認してください。
